## CodeOrbit Tech — Data Science Internship | Task 2

**Author:** Ritesh Kumar Singh

## Project Overview
This project explores the Titanic dataset using Python, Pandas, Matplotlib, and Seaborn to identify patterns, compare survival rates, visualize distributions, and inspect potential outliers.

## Objectives
- Explore the distribution of passenger ages.
- Compare survival rates by gender.
- Analyze survival rates across passenger classes.
- Examine the relationship between age and fare.
- Identify potential fare outliers using a boxplot and IQR.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Findings
- Overall survival rate: approximately 38.38%.
- Female survival rate: approximately 74.20%.
- Male survival rate: approximately 18.89%.
- First-class survival rate: approximately 62.96%.
- Second-class survival rate: approximately 47.28%.
- Third-class survival rate: approximately 24.24%.
- Potential high-fare outliers were identified using the IQR method.

## Visualizations
The notebook includes an age histogram, survival comparison charts, an age-versus-fare scatterplot, and a fare boxplot.

## How to Run
1. Install the required libraries: `pip install pandas matplotlib seaborn`.
2. Open the Jupyter Notebook.
3. Ensure the cleaned Titanic CSV is available.
4. Update the file path if required.
5. Run the notebook cells in order.

## Conclusion
This analysis demonstrates how exploratory data analysis can reveal patterns and relationships in a dataset. The findings describe associations and do not establish causation.
